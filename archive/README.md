# Archive Directory

This directory contains historical development artifacts archived before the final
publication freeze. These files are preserved for provenance and traceability but
are NOT part of the final research artifact.

## Contents

- `results_baseline/` — Phase 1 baseline evaluation results
- `results_phase3/` through `results_phase9/` — Intermediate development phase results
- `results_v2_benchmark/`, `results_v3_benchmark/` — Superseded benchmark versions
- `scratch/` — Development debug scripts

## When to Remove

These archives may be safely removed after the final paper is frozen and all
results have been independently verified. Until then, they provide a recovery
path for any historical comparison questions.
